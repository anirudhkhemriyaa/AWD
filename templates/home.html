Before You Import

Incorrect files can corrupt data or fail silently. Follow these rules to avoid errors.

File Rules
  • First row must be headers
  • Headers must match fields
  • No empty columns
  • UTF-8 encoding
  • .csv only
Data Rules
  • No duplicate primary keys
  • Foreign keys must exist
  • Dates: YYYY-MM-DD
  • Numbers without commas
  • No merged cells
